Dokumentasi

Panduan lengkap menggunakan semua fitur di Scrape Website.

Scraper Website
1

Masukkan URL

Tempelkan URL website yang ingin Anda scrape di kolom yang tersedia.

https://example.com
2

Klik Tombol Scrape

Tekan tombol "Scrape" untuk memulai proses pengambilan data website.

3

Download ZIP

Setelah selesai, file ZIP akan otomatis terdownload. Semua konten website tersimpan di dalamnya.

4

Ekstrak & Gunakan

Ekstrak file ZIP dan semua aset website — HTML, CSS, JS, gambar, video — siap digunakan.

IQC Studio
1

Masukkan Teks

Tulis pesan atau teks yang ingin Anda ubah menjadi gambar.

2

Generate Gambar

Klik tombol "Generate" untuk membuat gambar dari teks yang Anda masukkan.

3

Download

Klik tombol "Download" untuk menyimpan gambar ke perangkat Anda.

Dashboard
1

Lihat Statistik

Dashboard menampilkan total scrape, total file, rata-rata ukuran, dan waktu scraping terakhir.

2

Riwayat Aktivitas

Semua aktivitas scraping terekam di riwayat. Anda bisa melihat detail dan mendownload ulang ZIP.

3

Hapus Riwayat

Gunakan tombol "Hapus Semua" untuk membersihkan riwayat dan data ZIP di database.

Admin Panel
1

Akses Admin

Klik tombol "Admin" di navbar. Masukkan PIN: 3333

2

Kelola Tools

Tambah atau hapus tools yang muncul di halaman utama.

3

Kirim Pengumuman

Kirim pesan ke inbox semua pengguna melalui fitur "Kirim Pengumuman".

4

Maintenance Mode

Aktifkan mode maintenance untuk menampilkan halaman khusus ke pengunjung.
